## 前言：
#### 随着科技的进步，互联网的普及，计算机已然是家家户户必不可少的，可以使用计算机来进行看视频、编写代码、玩游戏……等等一系列操作，学过计算机基础的都知道，想要实现上述操作，需要在操作系统中进行的，操作系统又是工作在硬件系统上的，又硬件没操作系统，计算机可以工作，但是，反过来却不行，因为早期的计算机是没有操作系统的，目前，市面上主流的操作系统有Windows、MacOS、Linux、Unix、RTOS，其他的大多都是基于以上的改版

+ 方法二：直接使用*.iso文件进行安装
    步骤：
    - 1. 从官网下载，或者其他渠道下载，[这里提供一个](https://next.itellyou.cn/)，当然，还有其他替代方案
    - 2. 双击*.iso文件，或者右击选择挂载，然后找到挂载的盘符点进去
    - 3. 点击[setup.exe](#)文件
    - 4. 等待安装，安装过程中一直下一步即可
        - 注：如有特殊情况，无法跳过联网激活，可以尝试***shift*** + ***f10***打开类dos窗口，输入[oobe\bypassnro.cmd](#)，部分机型可能需要搭配***fn***按键，部分机型可能需要大写，但是类dos界面不区分大小写，具体什么原因我也不知道
    - 5. 系统安装完成，接着安装驱动，驱动可以选择使用第三方工具或者去官网安装，比如主板是联想的那就去联想官网，驱动安装完成后，系统才算安装完成，win10以上系统好像会后台自动安装驱动，但是，时间可能会比较久
